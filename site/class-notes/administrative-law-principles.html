二、依法行政：法律優位與法律保留

法律優位：行政行為不得違反憲法、法律及其他上位規範；有授權不代表可以違反上位法。法律保留：涉及人民權利的重要事項，特別是限制基本權利的措施，應檢驗是否具備足夠的法律或法律授權基礎；保留密度依事項性質、干預強度等判斷。

例：某機關僅以內部公告，創設法律未授權的罰鍰。首先應問「能否由公告創設處罰義務」，不能因目的在維持秩序就略過法源問題。

易錯：「依法行政」不等於所有行政細節都必須由立法院逐字規定；但也不能把行政規則或內部作業要點一律當成限制人民權利的充分授權。

三、明確性：讓人民知道自己應該做什麼

行政程序法 §5 要求行政行為內容明確。判斷時看處分相對人、標的、義務、期限及法律效果是否可得理解。法規範明確性與個別行政行為內容明確性彼此相關，卻不是完全相同的審查問題。

例：命令業者「儘速改善所有問題」，卻未說明改善項目、期限及判斷標準，可能有內容不明確的疑慮；若另有附件具體列明，則應合併判斷。

四、平等：同類案件原則上應同等處理

§6 禁止無正當理由的差別待遇。先找可比較的對象，再檢查差別標準及目的是否有合理關聯。差異處理不當然違法；反之，一律相同也未必真正平等。

例：同一類補助申請者，僅因承辦人個人喜好而採不同審核標準，欠缺正當理由。若法規依收入級距設定補助差異，則應檢驗分類目的與標準是否合理。

五、比例：三階段逐一審查

  1. 適合性：手段是否有助於合法目的達成？
  2. 必要性：若有數種同樣有效的手段，是否採取對人民權益損害較小者？
  3. 狹義比例性（衡量性）：手段造成的損害是否與所追求的公益顯失均衡？

例：某店家違反環境清潔規定，機關逕要求停業三個月。應先確認停業的法源，再比較限期改善、罰鍰或其他法定措施是否同樣有效；即使有助於衛生管理，也不代表必然通過必要性與衡量性。

易錯：「效果最好」不等於「必要」。必要性比較的是同樣能有效達成目的的替代手段；最後還要做利益衡量。

六、信賴保護：先分清違法撤銷與合法廢止

行政程序法 §8 保護人民正當合理的信賴。常用分析順序為：信賴基礎 → 信賴表現 → 信賴值得保護 → 公益與信賴利益衡量 → 法律效果。是否已發生具體財產安排、是否知悉處分違法，都是重要事實。

違法授益處分：在 §117 所定情形，機關得撤銷，但有不得撤銷的例外；§119 列舉詐欺、重大不實陳述及明知違法等信賴不值得保護的情形。撤銷後符合 §120 要件者，可能涉及合理補償。

合法授益處分：若因後續法規或事實變更等原因廢止，應改從 §123 以下檢查；不能直接把違法處分撤銷規則套在合法處分上。

例：機關誤核發補助，受領人依核准通知購買設備。應問處分原本是否違法、申請資料是否真實、人民是否有具體信賴支出，以及撤銷是否受到 §117 限制；不是只要「花了錢」就絕對不能撤銷。

七、誠實信用與不當聯結

誠實信用（§8）：行政機關應避免利用前後矛盾、突襲或其他失信方式對待人民；但單憑過去曾有某種做法，也不當然產生永久維持的權利。

不當聯結禁止：行政機關不得以不相干條件交換人民依法應得的利益。對行政處分附款，§94 明定不得違背處分目的，且須具有正當合理關聯。是否為合法附款，還應先審查 §93 的附款容許性。

例：核發餐飲營業許可，卻要求申請人贊助與食品安全毫無關係的活動，應檢查法源、附款容許性與目的關聯，不能以「對方自願」就免除審查。

八、裁量與基本原則的交叉適用

§10 要求裁量不得逾越法定範圍，且須符合授權目的。裁量不是「機關想怎麼做就怎麼做」；平等、比例與誠信仍拘束裁量。申論時可分別檢查裁量逾越、裁量怠惰、裁量濫用等問題，但應說明個案事實如何對應，不宜只背名詞。

作答順序：（1）辨識行政行為與法源；（2）確認權限、程序；（3）檢驗法律優位／保留；（4）檢驗明確、平等、比例、信賴等原則；（5）討論法律效果與救濟。

九、國考式申論題與完整涵攝

題目：甲依市府公告申請設備補助，提出真實資料並獲核准，隨即簽訂無法無償解約的設備採購契約。半年後市府發現承辦人誤解法規，原核准處分違法，遂以一紙公文撤銷補助，並要求甲全額返還。市府同時公告，日後所有補助申請人均須捐款支持市府指定活動，始予核准。試論其合法性。

參考答案｜爭點 → 法律依據 → 學說／實務問題 → 涵攝 → 結論
  1. 爭點：原補助處分性質與違法性、違法授益處分撤銷限制、信賴保護、返還請求，以及新增捐款條件是否合法。
  2. 規範：依行政程序法 §8、§117–§121 檢驗撤銷與信賴；涉及已受領給付的返還，另查 §127。新附款須查 §93、§94，並審查法律保留與平等、比例原則。
  3. 法律評價：甲提供真實資料且已負擔難以回復的契約義務，可能具值得保護的信賴；但仍須查明是否有 §119 事由，並比較撤銷所維護公益與信賴利益。不得僅因承辦人誤解法規，就省略 §117 的限制。
  4. 涵攝：若信賴利益顯然大於撤銷所欲維護公益且無 §119 事由，可能落入不得撤銷情形；如依法仍得撤銷，應續查 §120 合理補償。要求返還前須先釐清處分效力與 §127 要件，不能把「撤銷」與「直接命返還」視為同一行為。捐款條件與設備補助目的是否有正當合理關聯，顯有疑問，且需有相應法源。
  5. 結論：撤銷、補償、返還及新申請條件各有不同法定要件，須分別審查。甲最終能否保有補助，仍依完整事實與法規判斷。

十、五題自我檢核

Q1｜法律優位與法律保留有何不同？

法律優位問「行政不得違反上位法」；法律保留問「行政措施是否需要法律或法律授權作為依據」。

Q2｜比例原則三步驟？

適合性、必要性、狹義比例性（衡量性），依序檢驗。

Q3｜有差別待遇就違反平等原則嗎？

不一定。須比較案件是否同類，並判斷差別是否有正當理由。

Q4｜違法授益處分撤銷時，哪些信賴可能不值得保護？

依 §119，例如以詐欺、脅迫、賄賂取得處分；提供重大不正確或不完全資料；明知處分違法或因重大過失不知。

Q5｜營業許可附帶要求捐款，應查什麼？

先查附款法源及容許性（§93），再查與處分目的的正當合理關聯（§94），並兼顧法律保留及其他基本原則。
