竊盜・加重竊盜・侵占・搶奪・強盜・準強盜

資料界線：本頁整理先前課堂討論的財產犯罪爭點，並依臺灣現行刑法編寫原創解說，不是教材逐字內容、教師講義全文或特定判決摘錄。涉及學說／實務分歧時以爭點方式呈現，不虛構裁判字號。

考試先抓兩件事：財物原本由誰實際支配？行為人用什麼方式改變支配？先確定這兩件事，再選罪名。

一、六種犯罪：一張表建立判斷順序

罪名主要條文核心行為容易混淆的界線
竊盜§320Ⅰ未經同意，破壞他人對動產的持有並建立新的持有重點是持有移轉；不要求秘密進行
加重竊盜§321竊盜或竊佔行為伴隨法定加重情形是具特定加重要件的罪，不是機械地把 §320 與 §306 相加
侵占§335將原本自己持有的他人之物據為己有先合法或事實上取得持有，後續改變持有意思；須細查持有地位
搶奪§325乘人不備或以突然、直接方式奪取他人動產與強盜區別的關鍵：是否以法定方法使人不能抗拒
強盜§328以強暴、脅迫等方法使人不能抗拒而取物或使交付不能只看有沒有動手；須檢驗手段、強度與不能抗拒的關聯
準強盜§329竊盜或搶奪後，為法定目的而當場施以強暴脅迫不是所有偷後逃跑、推擠都自動成立；需檢驗目的、當場性與手段

二、先判斷「持有」：竊盜與侵占的分水嶺

刑法上的持有重視對物的事實支配關係，也須依社會生活觀念判斷；與民法上的所有權、占有權源並非完全相同。物的所有人可以不是當時的持有人。

  1. 店內商品：顧客趁店員轉身將架上商品藏入包中，原則上應先檢討竊盜；不能因店員沒看見就認為商品無人持有。
  2. 店員取走商品：不能僅憑「是店員」直接定侵占。須分辨店員是否有獨立持有，或僅為店主／公司的持有輔助者；若僅輔助持有，可能仍涉及竊盜。
  3. 代收款項：班代受託代收書款後據為己有，應先查明款項交付後由誰持有、委託關係與據為己有行為，再評價侵占或其他罪名。
  4. 暫時代看：請同學幫忙「看一下包包」，是否已移轉刑法上持有，取決於物的位置、實際管理程度及雙方安排；不宜單靠口頭稱呼認定。
答題句型：「本案首應釐清系爭動產於行為時由何人持有。若行為人破壞他人既存持有而建立自己持有，優先檢討竊盜；若其本已持有該物，嗣後以所有人姿態處分，則應檢討侵占。」

三、加重竊盜：§321 的獨立審查

先檢驗 §320 的基礎要件，再逐一核對 §321Ⅰ 各款，例如侵入住宅、毀越安全設備、攜帶兇器、結夥三人以上、乘災害之際或在特定大眾運輸場所／工具內犯之。加重要件與竊盜行為之關聯，應依具體款項與事實分析。

侵入住宅：住宅是否有人居住、行為人是否違反居住者意思進入，以及是否「而犯之」，均應獨立說明。§306 侵入住宅罪與 §321Ⅰ① 的關係，不能以「§320＋§306＝§321」取代構成要件分析；如同時可能成立其他罪名，再另論競合。

攜帶兇器：先判斷物品在客觀上是否足供傷害人之生命、身體；「攜帶」與「持以行兇」不同，通常不以實際使用為必要，但仍須檢驗行為時是否符合加重要件。不可把任何日常用品一律認定為兇器。

四、搶奪、強盜與準強盜：手段和時點最重要

搶奪：例如趁人不備突然扯走手提包。即使有一定物理力量，也不能僅憑「用力拉」直接跳到強盜；要看是否透過強暴、脅迫等手段，達到使人不能抗拒的程度。

強盜：先審查行為人是否為不法所有意圖，再看強暴、脅迫、藥劑、催眠術或其他方法，以及「使不能抗拒」與取財之間的關係。遇到被害人表面上沒有反抗，仍須從具體情境判斷，不能直接推定要件成立或不成立。

準強盜：前行為必須是竊盜或搶奪，後續為防護贓物、脫免逮捕或湮滅罪證，而「當場」施以強暴、脅迫。答題應拆解時間、地點連續性、目的及手段強度；相關程度問題有實務解釋爭議，勿以一句「偷後推人就是強盜」結案。

五、國考式申論模板

題目：甲在超商將架上商品放進外套準備離開，店員乙發現並追上。甲為脫免逮捕而推開乙後逃離。另設甲為負責保管倉庫物品之職員，私自將保管物搬回家。請分析甲可能成立之罪名。

參考答題架構（爭點 → 規範 → 學說與實務 → 涵攝 → 結論）
  1. 爭點：商品持有歸屬、竊盜既遂時點、推人是否構成準強盜，以及倉庫職員是否具獨立持有地位。
  2. 規範：先論 §320Ⅰ；如有法定加重事由再論 §321；當場為脫免逮捕施強暴脅迫，另審查 §329；保管物轉為自己所有則檢討 §335。
  3. 學說／實務爭議：簡述刑法持有的判斷、竊盜既遂與準強盜強暴程度的可能爭議，說明採取何一判準及理由；不虛構特定裁判。
  4. 涵攝：超商商品原在店家支配下，甲藏匿取走應分析是否已建立新的持有；推開乙須檢驗「當場」、脫免逮捕目的及強暴程度。倉庫職員若確實獨立持有受託保管物，據為己有則較接近侵占；若僅為持有輔助者，結論可能不同。
  5. 結論：依事實充分程度分別提出條件式結論，最後處理罪數／競合；不可跳過持有或強暴程度的論證。

六、三題快速自測

Q1：竊盜一定要偷偷拿才成立嗎？

不一定。關鍵在破壞他人持有、建立新的持有及主觀不法所有意圖；秘密性並非 §320Ⅰ 的必要文字要件。

Q2：店員把店裡商品拿走，必然是侵占嗎？

不是。先判斷店員是獨立持有者或僅有持有輔助地位，再依具體行為檢討侵占或竊盜。

Q3：竊盜後推開追捕者，一律成立準強盜嗎？

不是。仍須逐項分析 §329 的前行為、法定目的、當場性與強暴脅迫要件，並注意手段強度爭議。
